烬谷营造录隐私政策

更新日期：2026年11月9日

生效日期：2026年11月9日

适用游戏版本：安卓 v0.10.3

开发者公开名称：个个原

1、适用范围

本政策适用于《烬谷营造录》安卓 v0.10.3。开发者公开名称为“个个原”。下文“游戏”指本游戏自身，“平台”指您用于获取或运行游戏的 TapTap、TapPlay 等服务。游戏主体玩法在本地运行，不要求注册开发者账号，也没有由开发者运营的联网后台。

2、保存在设备上的数据

为继续游玩和恢复设置，游戏会在应用的数据空间中保存城市名称、地图种子、建筑与居民状态、资源、任务和灾害进度、结算与解锁记录、城市收藏及其封面，以及画质、音乐和音量等设置。城市名称可以使用默认名称，不需要真实姓名。游戏不会将这些本地存档自动上传给开发者。

3、截图保存与分享

您主动使用游戏内“拍照”时，游戏会生成当前城市画面并保存在应用数据空间；这不调用手机相机。只有您继续点击“保存到手机相册”，才会将这张游戏截图写入设备图片位置：Android 10 及以上使用系统媒体库，Android 8/9 保存到本应用专用图片目录，可再通过分享导出。游戏不浏览或读取您相册里的其他照片。

只有您点击“打开系统分享”，游戏才会调用系统分享面板，并向您选择的接收应用提供这张截图的临时读取权限；是否发送、发给谁由您决定。接收应用对截图的后续处理适用其自身规则。取消分享不影响核心游玩。分享用临时副本保存在应用缓存中，再次分享时会尝试清理已超过24小时的旧副本，不保证在满24小时的瞬间自动删除。

4、权限与服务边界

当前游戏包没有声明安卓联网、位置、通讯录、电话、相机、麦克风或广泛文件读写权限。游戏没有集成自建账号登录、广告、内购、统计分析或跨设备云存档 SDK，也不会通过游戏接收您的 TapTap 密码、手机号或身份证件信息。运行错误可能形成设备本地诊断日志；游戏没有配置将这些日志自动发送给开发者的服务。

游戏中的美术和配乐为随包提供的内容；游玩时不会把城市名称、存档或操作发送给生成式 AI 服务。

5、TapTap、TapPlay 与其他平台

通过 TapTap 下载、更新，或在 TapPlay 中免安装运行时，平台可能按其提示、设置和隐私政策，独立处理账号登录、实名认证、防沉迷、设备与使用信息，以及平台提供的存档备份等事项。免安装不代表平台不处理信息。本游戏没有直接接入平台账号登录或云存档接口，也不承诺已启用某项平台备份功能。

请阅读 TapTap 隐私政策：https://www.taptap.cn/doc/privacy-policy/ 。涉及平台账号、实名认证、平台备份或平台持有数据的请求，请通过该政策所列渠道联系 TapTap。

6、保存期限与数据管理

本地存档和设置会保留至您使用游戏或设备提供的管理功能删除。您可以在“城市收藏”中删除对应收藏；建立新城不会清除所有收藏、设置和解锁记录。对于直接安装的安卓版本，可通过系统应用设置清除本游戏数据或卸载应用，具体以系统提示为准。已导出到系统相册或发送给其他应用的图片，需要在相应相册或应用中另行删除。

TapPlay 内的游戏数据、系统备份或平台备份，请按对应平台的数据管理功能处理。开发者无法远程读取、删除或恢复您设备中的本地城市。删除前请确认不再需要相关进度。

7、主动反馈与联系我们

如对本政策、存档或数据处理有疑问，请在 TapTap 客户端搜索《烬谷营造录》，进入游戏页社区反馈，或进入游戏页显示的“个个原”开发者页面，使用其公开提供的反馈入口。

当您主动发布或发送反馈时，开发者可以看到您公开或主动提供的账号昵称、反馈内容和所附截图等信息，并将其用于答复请求、排查问题和保留必要的处理记录，保存期限以完成这些目的或适用要求所需为限。您可以通过同一渠道提出查阅、更正或删除您主动提供给开发者的信息的请求；平台上的帖子、账号及平台留存数据，仍需按平台规则管理。请勿在公开反馈中提交密码、身份证号、手机号或无关的敏感信息。

8、未成年人及政策更新

未成年人应在监护人指导下阅读本政策和使用平台服务，不要在城市名称或公开反馈中填写真实身份信息。平台的实名认证和防沉迷由平台按其规则处理。若后续版本增加联网收集、账号或其他数据处理功能，将更新本政策，并在相关处理开始前按适用要求进行告知和征求同意。

9、访问本政策网页

本政策网页通过 GitHub Pages 托管，提供静态说明，不设置账号登录、留言表单、广告或统计脚本，也不主动设置 Cookie。访问网页会产生网络请求；GitHub Pages 会出于安全目的记录和存储访问者的 IP 地址，无论访问者是否登录 GitHub。托管服务还可能根据其自身规则处理浏览器信息、访问时间等技术信息。这与游戏本地运行分开，不会因此读取或上传您的本地游戏存档。相关规则见 GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement 。
